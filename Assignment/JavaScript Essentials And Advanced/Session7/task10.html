Event flow in the DOM describes how an event moves through elements when an action occurs. It has three phases: capturing phase (top to target), target phase (the clicked element), and bubbling phase (target back to parent elements).

Example: In a Flipkart-style shopping cart app, if a user clicks an "Add to Cart" button inside a product card, the click event may bubble up to the product card or container and accidentally trigger another action, such as opening the product details page. Using event.stopPropagation() can prevent this unwanted behavior.
