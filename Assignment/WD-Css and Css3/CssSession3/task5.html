Explanation:

When an element has position: static, it stays in the normal page flow and takes its own space.

When we change it to position: absolute, the element is removed from the normal flow and can be placed anywhere inside its positioned parent using top, right, bottom, and left properties.

Example: WhatsApp notification badge uses position:absolute to place the unread message count on the top corner of a profile image without disturbing the layout.
